# Minha Trilha de Aprendizagem

Site simples criado como desafio final de Git e GitHub.

## Sobre o projeto

Este projeto demonstra o fluxo completo de versionamento:

- Criação de repositório com `git init`
- Vários commits com mensagens claras
- Uso de branch de funcionalidade
- Merge da branch
- Arquivo `.gitignore`
- Publicação no GitHub
- README explicativo

## Conteúdo do site

- **Página inicial** com boas-vindas
- **Seção "O que aprendi"** com cards sobre os tópicos estudados
- **Lista de comandos Git** mais usados
- **Rodapé** com informações do projeto

## Tecnologias

- HTML5
- CSS3 (layout responsivo)
- JavaScript (opcional, apenas console.log)

## Como rodar localmente

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
