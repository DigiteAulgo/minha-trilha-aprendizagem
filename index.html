O que aprendi

1. O que é versionamento?

Versionamento é o processo de controlar e registrar as diferentes versões de arquivos ou de um projeto ao longo do tempo. Cada alteração importante cria um novo estado (versão) do projeto.

2. Git × GitHub

Git é o sistema de controle de versão que funciona no computador. GitHub é a plataforma online que hospeda repositórios Git e facilita a colaboração (Pull Requests, Issues etc.).

3. Prepare o ambiente

Instale o Git, configure nome e e-mail com git config --global e verifique com git --version e git config --list.

4. Crie o primeiro repositório

Use mkdir, entre na pasta e rode git init. Depois confira o estado com git status.

5. Comandos essenciais

Fluxo diário: editar → git status → git add → git commit → git log. Também use git diff para ver diferenças.

6. Commits claros

Faça commits pequenos e com mensagens objetivas. Evite mensagens genéricas como “alterações”. Prefira: “Adiciona formulário de contato”.

7. Branches e merge

Branch é uma linha de desenvolvimento isolada. Crie com git switch -c nome, volte com git switch main e integre com git merge.

8. Conecte ao GitHub

Crie o repositório no GitHub, adicione o remoto com git remote add origin URL, renomeie a branch para main e envie com git push -u origin main.

9. Clonar e colaborar

Use git clone para copiar um repositório existente. Fluxo de colaboração: git pull → editar → commit → git push.

10. .gitignore e boas práticas

Ignore arquivos desnecessários (node_modules/, .env, *.log). Faça commits pequenos, use branches, atualize antes de trabalhar e nunca versionar senhas ou tokens.

Lista de comandos Git

  • git init — Cria um novo repositório Git
  • git status — Mostra o estado dos arquivos
  • git add . — Adiciona todos os arquivos à área de stage
  • git commit -m "mensagem" — Registra as mudanças com uma mensagem
  • git log --oneline — Exibe o histórico de commits de forma resumida
  • git branch nome-da-branch — Cria uma nova branch
  • git checkout nome-da-branch — Muda para outra branch
  • git merge nome-da-branch — Integra uma branch na atual
  • git remote add origin URL — Conecta ao repositório remoto
  • git push -u origin main — Envia os commits para o GitHub
  • git clone URL — Copia um repositório remoto
  • git pull — Atualiza o repositório local com as mudanças remotas
